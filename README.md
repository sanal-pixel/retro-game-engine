# Retro Game Engine
two games tic tac toe and snake


We made a simple and amazing gaming project developed in C, and featuring clssic, snake and Tic Tac Toe, kind of modular and structured design 

## Features
- **Snake Game** – Classic snake game, w,a,s,d button to play.
- **Tic-Tac-Toe** – Two-player turn based gameplay. Player X and O, pure logic.
- **Modular Architecture , UI ** – Display, Separate game engines & rendering components.
- **Game Analytics** – Tracks basic game data & statistics.
- **File Handling** – Supporting storing , manages game data.

## Tech Stack
- C Programming
- GCC Compiler
- Makefile
- Standard C Libraries
- VS Code

## Project Structure
We organized the project according to the given file, and and divide into separate modules, like game logic, UI, Analytics, & file operations, making the  things and code easy to maintain and devlope further.
